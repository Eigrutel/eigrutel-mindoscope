# Use mindoscope

Version 1.0.0 · 17-11-2026

## Create and open maps

Use New map, enter a title and choose Create map. Switch maps using the title menu. Use the folder to import files without replacing existing maps.

## Add cells

Use a cell’s + to add a child with the parent’s background, opacity and border, while keeping level typography. Use + Cell for an unlinked cell. Tap text to edit it and the yellow details button to edit notes and styles.

## Arrange and move branches

Choose free placement or a directional layout. In automatic layouts, drag the six-dot grip or the cell background in a view without controls. Drop in another cell’s centre to change parent, or near its top/bottom edge to reorder. In vertical layouts, use left/right edges. Move descendants with the branch.

## Use free placement

Drag a cell or its grip. Check the box beside directions to include descendants, including folded ones. Reattach a branch from its cell details. Enable automatic parent styling in settings, with or without typography. Keep the existing parent when merely moving a cell freely.

## Navigate and change views

Drag the background, pinch with two fingers or use + and − to zoom. Choose Fit map to see everything. Use the eye with a red underline to switch between two views. Enable the optional compact third view in settings.

## Edit images and styles

Add an image, adjust its crop and confirm. Use Whole image to reset the crop and cell details to change its size. Use PNG for transparency. Choose fonts, sizes, alignment, text and cell colours in cell details. Adjust background opacity or hide the border. Apply styles to descendants with or without typography. Set level 1–5 typography and import or remove custom fonts in settings.

## Edit multiple elements

Choose Select, select cells and choose Modify. Check only the properties to apply. Choose Modify links, select individual links or all links, then apply a graphical line style. Finish selection to resume normal editing.

## Connect cells and add notes

Choose + Link, select a parent and child, then confirm. Add multiple links where needed. Tap a line to edit its label, notes, image and style. Use the primary branch for folding and grouped movement. Find technical link numbers in PDF notes.

## Add shapes

Choose + Shape to add a rectangle, ellipse, cloud or brace. Drag to move, resize with handles and rotate with the round handle. Set colour, opacity and stacking order, then confirm. Tap a shape to edit it.

## Fold and search

Use a cell’s chevron to hide or reveal descendants. Search across all maps, cell notes and link details. Use the result’s magnifier to navigate to the matching item.

## Lock and undo

Close the padlock to prevent editing while keeping navigation, view changes, saving and exports available. Use Undo and Redo in the toolbar. Press Escape to cancel a move.

## Copy and delete maps

Create a map from a cell using its outward-arrow button, with or without descendants. Insert an independent copy of another map using the inward-arrow button. Delete a map with the toolbar bin after confirmation; use Undo or Restore the last deleted map to recover it.

## Save and import

Use the disk button to save one map or all maps as .mindo, including images and fonts. Keep regular file backups outside the browser, especially before clearing browser data. Open legacy .mindmap and .mindmaps files, Univers or Pop JSON, Univers HTML slideshows and Markdown. Import multiple Univers maps as separate maps.

## Export

Choose PDF, set page size and orientation, then create and download the file. Include the map’s current view and background, including night mode. Enable cell or link notes to include visible items containing text or an image; exclude descendants hidden by collapsed branches. Follow clickable PDF URLs. Use Markdown in settings to export hierarchical text without images.

## Reset

Use Reset all settings to restore preferences and map backgrounds while keeping maps. Use Reset everything and confirm to also delete maps and imported fonts. Save a backup first.

## Use the keyboard

Press Enter to add a child while editing a cell, or Shift + Enter for a line break. Outside text fields, use Ctrl / ⌘ + Z to undo.
